# 六點輸入法（6d-IME）

適用於臺灣視障使用者的 NVDA 點字鍵盤輸入插件，讓標準鍵盤的 `f d s j k l` 六個按鍵化身為六點點字鍵，支援注音、英文及黑點點字多種輸入模式。

---

## 輸入模式

按 `NVDA+Ctrl+7` 循環切換，每次切換 NVDA 會語音報讀目前模式名稱。

| 模式 | 說明 |
|------|------|
| **一般輸入法** | 插件完全透明，還原為正常鍵盤 |
| **注音點字** | 用點字格輸入注音符號，配合大千式注音 IME |
| **黑點點字** | 直接輸出 Unicode 點字字元（⠀–⠿），適合輸入點字符號本身 |
| **電腦點字** | 依照 en-us-comp8 表反向翻譯，每格即時上字 |
| **UEB 一級** | 依照 UEB Grade 1 表反向翻譯，每格即時上字 |
| **UEB 二級** | 依照 UEB Grade 2 縮寫表翻譯，空白鍵確認後整字送出 |

反向切換：`NVDA+Ctrl+Shift+7`

---

## 鍵位配置

```
左手：f = 點1　d = 點2　s = 點3
右手：j = 點4　k = 點5　l = 點6
      A = 點7（退格）
      ; = 點8（Enter）
  Space = 確認／空白
```

---

## 快速鍵總覽

| 快速鍵 | 功能 |
|--------|------|
| `NVDA+Ctrl+7` | 正向循環切換模式 |
| `NVDA+Ctrl+Shift+7` | 反向循環切換模式 |
| `NVDA+Ctrl+8` | 開啟模式選擇設定 |

---

## 模式選擇設定

按 `NVDA+Ctrl+8` 開啟設定視窗，可自訂 toggle 循環要包含哪些模式（至少選兩個）。例如只保留「一般輸入法」和「注音點字」，toggle 時就只在這兩個之間切換，不經過其他模式。

---

## 注意事項

- **切換至電腦點字 / UEB 模式時，中文 IME 會自動暫停**，避免注音框干擾英文輸入；切回其他模式後自動恢復。
- **Ctrl / Alt 組合鍵不受影響**，`Ctrl+A`、`Alt+Tab` 等快捷鍵在任何模式下均正常運作。
- 點字顯示器使用者可在「NVDA 輸入手勢」設定中，為 toggle 和模式選擇另外綁定點顯器按鍵。

---

## 系統需求

- NVDA 2025.1 以上
- Windows 10 / 11

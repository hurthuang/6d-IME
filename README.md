# 六點輸入法（6d-IME）

NVDA 附加元件，提供六點點字鍵盤多模式輸入，支援注音點字、電腦點字（comp8）、UEB 英文點字、直接輸出 Unicode 點字字元，以及 Nemeth 數學符號輸入。

## 需求

- NVDA 2026.1 以上（64 位元）
- Windows 10 / 11
- 已安裝微軟注音輸入法（注音點字模式需要；進入注音點字模式時會自動切換過去）

## 鍵位配置

六點鍵使用標準點字鍵盤佈局：

| 按鍵 | 點位 |
|------|------|
| F    | 點 1 |
| D    | 點 2 |
| S    | 點 3 |
| J    | 點 4 |
| K    | 點 5 |
| L    | 點 6 |
| 空白 | 確認／送出 |
| A    | 點 7（退格） |
| ;    | 點 8（Enter） |

空白鍵和點字鍵一起按時當成第 9 個點字鍵，全部放開才判斷，所以「空白＋點456」和「點456＋空白」都可以。打字時空白鍵和前一格重疊（沒有指令的組合），會照順序送出該格再送空白。

## 快捷鍵

| 鍵盤 | 點字顯示器 | 功能 |
|------|-----------|------|
| Ctrl+NVDA+7 | 空白＋點456 | 開啟六點輸入（Ctrl+NVDA+7 也可關閉） |
| 空白＋點456（空白＋J+K+L） | 空白＋點456 | 切換到下一個已勾選的點字模式 |
| 空白＋點7（空白＋A） | 空白＋點7 | 關閉六點輸入 |
| 空白＋點134 | 空白＋點134 | 電腦點字模式下進入 Nemeth 數學子模式 |
| Ctrl+NVDA+8 | | 開啟模式偏好設定 |
| Alt+Shift+NVDA+M | | 開啟 Nemeth 數學符號選單（任何模式下可用） |

關閉時切換回一般輸入法；開啟時進入偏好設定中第一個勾選的模式。

按住點456 不放，持續按空白可連續切換。

鍵盤在六點輸入關閉時要照常打字，無法分辨空白＋點456，所以鍵盤要用 Ctrl+NVDA+7 開啟。

## 點字顯示器

有點字鍵的點字顯示器（例如 Focus 系列）都可以直接輸入，6d-IME 只使用 NVDA 對所有點顯器共通的點字鍵手勢，不針對特定機型。

- 單獨的點、單獨的空白：六點輸入開啟時由 6d-IME 處理；關閉時交回 NVDA 原本的點字輸入（點7 倒退刪除、點8 Enter、點7+8 轉譯）
- 只接管最少必要的空白＋點組合，其他組合維持點顯器原本的功能：
  - 空白＋點456：不論開關都接管（會蓋掉點顯器原本的功能，例如 Focus 的 Ctrl+End）
  - 空白＋點7：只在六點輸入開啟時接管
  - 空白＋點134：只在電腦點字模式接管，其他時候維持點顯器原本的功能（例如 Focus 的 Alt）
- 按鍵可在 NVDA 選單 > 偏好設定 > 輸入手勢 >「六點輸入法」類別裡修改
- **不要和「點字輸入法助手」（BrlIMEHelper）同時啟用**，兩者都會接管點顯器的點字鍵

## 自動切換微軟注音

進入注音點字模式時，若前景程式的輸入法不是微軟注音，會自動切換過去並設成中文模式（微軟注音會記住上次的中／英數狀態）；注音點字模式下切換視窗時也會再確認一次。關閉六點輸入時切回原本的輸入法；若期間自己換過輸入法，則不會改回去。

## 輸入模式

### 注音點字

使用臺灣注音點字輸入中文。點字格對應規則來自 `Phn.tbl` 對照表。

- 輸入聲母＋韻母自動送出，再以調號確認
- 標點符號以點字格序列輸入：
  - 雙格序列（如 ⠒⠒ = ：）輸入第二格時立即送出
  - 支援標點符號輸入，單格標點輸入後需按空白鍵

### 黑點點字

直接輸出 Unicode 點字字元（U+2800–U+28FF），用於需要插入點字符號的場合。

### 電腦點字（comp8）

使用 `en-us-comp8-ext.utb` 對照表輸入英文及符號。每格即時送出對應字元，Space 送出空格。

**Nemeth 數學子模式**（v1.3 新增）：在電腦點字模式下，按 Space+dots134（⠍）進入 Nemeth 數學子模式，語音報「數學」。輸入 Nemeth 點字格序列後按 Space，自動查表送出對應 Unicode 數學符號，並返回電腦點字模式，語音報「電腦點字」。

### UEB 一級

使用 `en-ueb-g1.ctb` 對照表，字母逐格翻譯後即時送出。

### UEB 二級

使用 `en-ueb-g2.ctb` 縮寫對照表，整個單字輸入完畢後按 Space 一次送出翻譯結果。

## Nemeth 數學符號輸入

### 六點輸入

在電腦點字模式下按 **Space+dots134** 進入 Nemeth 子模式後，以六點鍵輸入 Nemeth 數學點字格序列，按 Space 送出符號。採貪婪最長匹配，可連續輸入多個符號後一次送出。

對照表來源為 liblouis `nemethdefs.cti`，共收錄約 296 個符號 pattern（最長 12 格），涵蓋：

| 類別 | 範例 |
|------|------|
| 四則運算 | ÷ × ± − ∞ π |
| 比較關係 | = > < ≥ ≤ ≠ ≈ |
| 集合 | ∈ ∉ ∪ ∩ ∅ |
| 幾何 | ∠ △ ○ □ ⊥ ∥ |
| 邏輯推理 | ∵ ∴ → ⇒ ⇔ ∀ ∃ |
| 希臘字母 | α β γ δ ε π σ θ ω |
| 微積分 | ∂ ∫ ∬ ∇ |

部分常用符號的 Nemeth pattern：

| 符號 | pattern | 點字 |
|------|---------|------|
| ÷ | 46-34 | ⠨⠌ |
| × | 4-16 | ⠈⠡ |
| ± | 346-36 | ⠬⠤ |
| = | 46-13 | ⠨⠅ |
| > | 46-2 | ⠨⠂ |
| < | 5-13 | ⠐⠅ |
| ≥ | 46-2-156 | ⠨⠂⠱ |
| ≤ | 5-13-156 | ⠐⠅⠱ |
| ≠ | 34-46-13 | ⠌⠨⠅ |
| π | 46-1234 | ⠨⠏ |
| ∞ | 6-123456 | ⠠⠿ |
| ∈ | 4-15 | ⠈⠑ |
| ∠ | 1246-246 | ⠫⠪ |
| ∴ | 6-16 | ⠠⠡ |
| → | 1246-135 | ⠫⠕ |

### 符號選單

按 **Alt+Shift+NVDA+M** 開啟 Nemeth 符號選單，可在任何模式下使用。

選單分為八個類別：四則運算、比較關係、集合、幾何、邏輯推理、希臘字母、微積分、全部符號。

操作方式：

| 按鍵 | 功能 |
|------|------|
| ↑ ↓ | 移動選項 |
| Enter / Space / → | 進入類別 或 插入符號 |
| ← / Backspace | 返回類別層 |
| Escape | 關閉選單 |

「全部符號」類別列出 `nemethdefs.cti` 所有可用 pattern，共約 296 個，依格數排序。每項顯示格式為「符號名稱＋點字 pattern」。

## 偏好設定

Ctrl+NVDA+8 開啟模式選擇對話框，勾選空白＋點456 循環中要包含的點字模式。至少需勾選一個模式。設定儲存於 NVDA 設定檔（`[6dIME]` 區段）。

## 已知限制

- Nemeth 子模式僅在電腦點字（comp8）模式下可用
- `nemethdefs.cti` 中含內部空格格（如分數、矩陣結構）的 pattern 不支援六點輸入，可透過符號選單存取
- `√`、`°`（獨立格）、`²`、`³` 不在 `nemethdefs.cti` 中，僅可透過符號選單輸入
- 從注音模式切換到其他模式時，若曾送出音節給 IME 但尚未整句確認，插件會自動送 Enter 提交
- 同一個視窗在同一個 NVDA session 中，**第一次**切進注音點字模式再切出時，組字內容仍可能殘留、跑到後續輸入前面（推測是該視窗的注音 IME 第一次被關聯成中文時，TSF 尚未完全綁定好）。只要切出去再切回注音點字模式一次，之後同一視窗就會恢復正常，不會再發生
